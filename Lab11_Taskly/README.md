# Lab 11 Taskly Testing

Taskly hỗ trợ thêm, hoàn thành, xóa, mở chi tiết và đổi tên task. Repository/model tách riêng. Unit, widget, navigation và end-to-end UI test nằm trong `test/`.

```powershell
flutter pub get
flutter run
flutter test
```

DevTools Inspector/Performance trace phụ thuộc vào việc chạy emulator hoặc thiết bị; mở bằng `flutter pub global run devtools` khi app chạy debug.
