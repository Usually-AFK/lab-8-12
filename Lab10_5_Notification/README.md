# Lab 10.5 Local Notification

Ứng dụng khởi tạo plugin, xin quyền notification và có nút gửi thông báo thử. Trên Android 13+, chấp nhận quyền khi hệ thống hỏi; trên iOS chấp nhận alert permission.

```powershell
flutter pub get
flutter run
```

Notification của ứng dụng cần được cho phép trong cài đặt hệ điều hành.
