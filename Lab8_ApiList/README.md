# Lab 8 API-powered List

Ứng dụng lấy bài viết từ JSONPlaceholder, parse sang `Post`, dùng `ApiService` và `FutureBuilder`, hiển thị loading/error/retry và danh sách có thể kéo làm mới.

```powershell
flutter pub get
flutter run
```

API: `https://jsonplaceholder.typicode.com/posts`. Có thể chạy `flutter run -d chrome` để thử trên web.
