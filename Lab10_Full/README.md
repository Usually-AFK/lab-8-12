# Lab 10 Full Authentication

Project tích hợp đăng nhập DummyJSON, lưu/khôi phục session bằng SharedPreferences, gửi local notification khi đăng nhập thành công và cung cấp Google Sign-In qua Firebase Auth.

```powershell
flutter pub get
flutter run
```

Tài khoản API mẫu: `emilys` / `emilyspass`. Để dùng Google Sign-In, làm các bước Firebase trong [Lab10_4_FirebaseGoogleSignIn](../Lab10_4_FirebaseGoogleSignIn/README.md) nhưng chạy `flutterfire configure` trong thư mục `Lab10_Full` để sinh cấu hình cho đúng app. Mở quyền notification trên thiết bị khi được hỏi.
